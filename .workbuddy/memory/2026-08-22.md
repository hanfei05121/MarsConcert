## LyricsOverlay 长停顿倒计时（用户需求）
- 需求：两句歌词间停顿 >5s 时，临近下一句的最后 5 秒显示 5 格倒计时，每秒熄灭一格；短停顿不显示。
- 改动（仅 LyricsOverlay.vue，复用现有 `lines/active/now` props）：
  - `targetLine`（下一句，未开唱=首句）、`pauseGap`（上一句/0 → 下一句的间隔）、`remain`、`countdown`（0=隐藏，否则 5→1）；
  - 模板在两行歌词下加 `.countdown` 5 个 `.dot`，`n <= countdown` 的格点亮（粉色 #ff5ca8 + 辉光）；
  - 常量 `PAUSE_GAP_SEC=5`、`PAUSE_COUNTDOWN_SEC=5`。
- 覆盖场景：长前奏最后 5s 也会出倒计时（与 visible 预览并存）；末句无下一句/短停顿均不显示。
- 验证：vue-tsc 通过；逻辑自测 9 例全符合预期。

### 倒计时调整（用户追加）
- 位置：从居中改到**左上角歌词上方**（`.countdown` 移到两行歌词之前、`justify-content: flex-start` 靠左）。
- 规则：**歌曲开头恒显示倒计时**——未开唱（active=-1）不再受"停顿>5s"限制，短前奏（如 3s）也会 3→2→1；
  句中停顿仍仅当停顿 >5s 才启用（避免正常演唱节奏被打扰）。
- 验证：vue-tsc 通过；自测 11 例全符合预期。
- 再调整（用户追加）：**句中停顿阈值 5s → 10s**（`PAUSE_GAP_SEC=10`，恰好 10s 不触发、超过才触发）；歌曲开头恒显示不变。
- 再调整（用户确认）：**句中停顿阈值 10s → 15s**。原因：烟火里的尘埃首句 4.543s / 次句 14.810s（间隔 10.27s>10s）导致片头两段倒计时（0~4.5s 片头 + 9.8~14.8s 句中）接连出现；提到 15s 后正常换气停顿不再触发，明显间奏（≥15s）仍提示。
- 再调整（用户反馈）：**倒计时不再固定靠左，跟随「下一句」槽位左右交替**——偶数 active 下一句在下槽（右下）→ 靠右；奇数/未开唱 → 靠左（`countdownRight = active>=0 && active%2===0`，模板加 `.right` class 切 `justify-content: flex-end`）。
